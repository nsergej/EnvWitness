# Support

Use GitHub Discussions for questions, installation help, configuration review, and plugin design. Use GitHub Issues for reproducible defects and accepted feature proposals.

Before asking for help:

```bash
envwitness version
envwitness verify your-capsule.evw
envwitness inspect your-capsule.evw
```

Do not attach production capsules publicly until you have reviewed their contents. Security-sensitive reports belong in GitHub private vulnerability reporting.
